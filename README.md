# Calculatrice 🧮

Une application de calculatrice intuitive et légère, développée pour un usage simple et rapide.

---

## ✨ Fonctionnalités

- **Opérations de base** : Addition, soustraction, multiplication et division.
- **Interface épurée** : Prise en main immédiate et design minimaliste.
- **Léger & Rapide** : S'exécute instantanément sans alourdir le système.
